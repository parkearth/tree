# 空樹穴巡查填報 PWA — 設定步驟

## 檔案
| 檔案 | 用途 |
|---|---|
| index.html | 手機填報網頁（單一檔，含樣式與程式） |
| sw.js、manifest.json、icon.svg、icon-192.png、icon-512.png | 讓網頁可「加到主畫面」並離線開啟 |
| gas-connector.gs | 貼到 Google Apps Script 的後端，負責寫入試算表、存照片 |

## 1. 把缺失表轉成 Google 試算表
Apps Script 只能寫入 Google 試算表，不能寫入雲端硬碟裡的 .xlsx 檔。
1. 在雲端硬碟開啟「空樹穴巡查缺失表.xlsx」→ 檔案 → **儲存為 Google 試算表**。
2. 開啟新產生的試算表，複製網址中 `/d/` 和 `/edit` 之間那串，就是 **試算表 ID**。

## 2. 部署後端
1. 在該試算表：擴充功能 → Apps Script，刪掉預設內容，貼上 `gas-connector.gs`。
2. 修改最上方 `CONFIG`：`SHEET_ID` 貼上試算表 ID；`TOKEN` 改成組內通行碼。
3. 選函式 `testSetup` → 執行，依畫面完成授權。執行記錄會顯示照片資料夾網址和一筆地址反查結果。
4. 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」、誰可以存取「**所有人**」→ 部署，複製網址（結尾是 `/exec`）。
5. 之後修改程式：部署 → 管理部署作業 → 編輯 → 版本選「新版本」，網址不變。

## 3. 架設網頁（擇一）
- **GitHub Pages**：新建 repo，上傳 index.html、sw.js、manifest.json 和 3 個圖示 → Settings → Pages → 分支 main → 取得 `https://帳號.github.io/repo/`。
- 也可以用 Netlify、Cloudflare Pages 等任何 HTTPS 靜態空間。定位和離線功能需要 HTTPS。

想讓組員免設定：把 `index.html` 裡 `DEFAULTS.GAS_URL` 填好再上傳；不改也行，第一次開啟到「設定」頁貼網址即可。

## 4. 手機使用
1. 用 Chrome（Android）或 Safari（iPhone）開網址 → 「加到主畫面」。
2. 「設定」頁貼 GAS 網址、通行碼 → 測試連線。
3. 「填報」：選行政區 → 定位帶入地址並補方位 → 選缺失種類 → 拍缺失照片 → 送出。
4. 沒網路時會存在手機，紀錄頁顯示「等待中」，恢復網路或重新開啟 App 時自動上傳。
5. 改善完成後：「紀錄」→ 表內缺失 → 對該序號按「補改善照片」。

## 寫入規則
- 從第 4 列起找第一個「行政區、位置、缺失種類」都空白的列寫入；表內預留列用完後自動新增一列，沿用上一列格式和下拉選單，序號 +1。
- E、F 欄放照片縮圖（`IMAGE()` 公式），儲存格註解有原圖連結；照片存在試算表同一層的「空樹穴巡查照片」資料夾，檔名為 `日期時間_序號_缺失/改善.jpg`。
- G 欄備註會自動附上樹穴編號、GPS 座標、填報人和巡查時間。
- 每筆資料有唯一編號，網路不穩重送也不會重複寫入。
- 標題列（A1 的日期區間、G2 資料日期）不會被改動，換週時請手動更新。
- 若機關網域禁止「知道連結的人可檢視」，試算表內縮圖會顯示不出來，但註解的原圖連結仍可在登入後開啟。
